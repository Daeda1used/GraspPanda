    GSNet¶

    Run GSNet in five minutes from the authors' checkpoint: the weights, a first picture, the same from Python and in the browser, a first number on the benchmark. Then the options of every slot: what fits where GSNet ships its components, and what was measured for each.

    Run GSNet in five minutes¶

    From the authors' checkpoint to grasps on a scene: on the command line, from Python or in a browser, then a first number on a part of the benchmark. Every command here is run by the test suite (by parsing it, on a toy detector, or on the files it needs); what each printed when it was measured is said under it, with the date, the commit and the machine. The numbers come from the method's metafile and five_minutes.json.

    1. The weights¶

    GraspPanda trained GSNet once (the reproduced rows of its README), but those weights are not published yet: trained on GraspNet-1Billion (CC BY-NC-SA 4.0); whether and where these weights are published has not been decided. What you can download is the checkpoint released with the reference code:

    • File: minkuresunet_realsense.tar, from https://drive.google.com/file/d/1RfdpEM2y0x98rV28d7B2Dg8LLFKnBkfL/view?usp=sharing
    • Licence: academic, non-commercial (SJTU), as the reference repository; trained on GraspNet-1Billion (CC BY-NC-SA 4.0)
    • SHA-256: a0b9d85b300e40c76b66d092de62138d74757d6b7c2037f0d364f33960c54aa9

    Convert it once, from the root of your GraspPanda checkout (the converter is a tool of the repository; it is not installed with the package):

    python -m tools.convert_checkpoint minkuresunet_realsense.tar gsnet_realsense.pth \
    --source-format graspness-unofficial --camera realsense

    It writes gsnet_realsense.pth: every tensor of the authors' file under the name of the module that plays its role here, no value changed, with a note of the file it came from. A tensor left over or missing stops the conversion with a report; nothing is ever loaded partially.

    Before you use it. It loads strictly and runs, but it is far below the paper: its best-ranked grasps run into the scene, so use it with the collision filter. Its README says what is known.

    2. Grasps on the example scene¶

    grasppanda demo gsnet/gsnet_sunet14_g1b-realsense_10e \
    --weights gsnet_realsense.pth --example --collision-filter

    --example is the synthetic table-top scene that ships with GraspPanda: no dataset and no download. The command prints the config and its hash, how the weights loaded (every tensor matched, none missing), the test pipeline, the cloud, how many grasps the model predicted and how many the collision filter left (the config's variant cd: ModelFreeCollisionFilter), and the ten best grasps. It writes into work_dirs/gsnet_sunet14_g1b-realsense_10e/demo/:

    • grasps.npy: the grasps that are left, (G, 17) float32 in the GraspNet layout, best first, camera frame, metres;
    • grasps.png and grasps.gif: the cloud with the 30 best grasps, still and swinging around the scene;
    • example/: the scene as files (depth.png, rgb.png, mask.png, intrinsics.txt).

    Measured with the authors' released file, converted: 14.8 s for the whole command; 15,000 points to the model, sampled from 316,254 in the workspace; 1024 grasps predicted, 418 left after ModelFreeCollisionFilter (2026-10-15, commit 0ddca31, one NVIDIA RTX A6000 shared with other jobs).

    Measured with the weights trained here (not published): 16.6 s for the whole command; 15,000 points to the model, sampled from 316,254 in the workspace; 1024 grasps predicted, 689 left after ModelFreeCollisionFilter (2026-10-15, commit ea6268b, one NVIDIA RTX A6000 shared with other jobs).

    The scene files stand in for a camera. On your own depth image, as on these:

    grasppanda demo gsnet/gsnet_sunet14_g1b-realsense_10e \
    --weights gsnet_realsense.pth \
    --depth work_dirs/gsnet_sunet14_g1b-realsense_10e/demo/example/depth.png \
    --intrinsics work_dirs/gsnet_sunet14_g1b-realsense_10e/demo/example/intrinsics.txt \
    --workspace -0.25 -0.2 0.35 0.25 0.2 0.8 \
    --collision-filter --out work_dirs/camera

    GSNet was trained on clouds cropped around the objects; on a camera image, --workspace (a box in the camera frame, metres) or --mask does that crop. Units and frames, the depth scale and the intrinsics: Your own camera.

    3. The same from Python¶

    from grasppanda import GraspInferencer
from grasppanda.apis import example_scene

scene = example_scene()  # the scene of --example
inferencer = GraspInferencer(
    "gsnet/gsnet_sunet14_g1b-realsense_10e", "gsnet_realsense.pth"
)
grasps = inferencer(
    depth=scene.depth, intrinsics=scene.intrinsics,
    depth_scale=scene.depth_scale, mask=scene.mask,
    table_from_camera=scene.table_from_camera, collision_filter=True,
)
print(len(grasps), grasps.sort_by_score().to_graspnet_array()[:3])

    It runs the demo's pipeline on the demo's input, so it returns the demo's 418 grasps (the test suite checks that the two give the same array, on a toy detector). mask= stands in for the segmentation the config crops the workspace with; on your camera, pass a mask from any segmentation or workspace=(xmin, ymin, zmin, xmax, ymax, zmax) in metres. The fields of a grasp and what else the call takes: From Python.

    4. In the browser¶

    # ~/grasppanda_weights: the folder that holds gsnet_realsense.pth
grasppanda explore --weights-dir ~/grasppanda_weights

    The page opens at http://127.0.0.1:8765/. In the tab Run a method choose GSNet: gsnet_realsense.pth is chosen for you by its name. Keep the example scene (or upload a depth image with its intrinsics), tick the collision filter and press Run: the page shows the picture, the best ten grasps, the counts through the post-processing and the command that does the same in a terminal. The server listens on your machine only, reads weights only from that folder and downloads nothing: Run in the browser.

    5. A first number on the benchmark¶

    With GraspNet-1Billion on disk (export GRASPPANDA_GRASPNET1B_ROOT=..., see Dataset preparation), score the weights on every 64th frame of the seen test scenes, 120 frames:

    grasppanda test gsnet/gsnet_sunet14_g1b-realsense_10e \
    --weights gsnet_realsense.pth \
    --opts data.test.dataset.split=test_seen data.test.dataset.frame_step=64 evaluation.num_workers=4

    It prints AP, AP0.8 and AP0.4 for every variant of the config, raw (the predictions as they are) and cd (with the collision filter), and writes a result record per variant into the run directory under work_dirs/. Testing needs no derived asset; the evaluator extracts a cache from the dataset's object models the first time it runs, which the times below do not include.

    The options of every slot¶

    Every slot of GSNet (gsnet/gsnet_sunet14_g1b-realsense_10e), what the method ships with there, the options that fit it and the ones that do not, each with what was measured: the cells of the measured grid that replace that one slot of GSNet. The method itself: its README. The same lists, with every message whole, in a terminal or as JSON:

    grasppanda compose gsnet/gsnet_sunet14_g1b-realsense_10e --list            # every slot
grasppanda compose gsnet/gsnet_sunet14_g1b-realsense_10e --list <slot> --json

    One run, seed 0, 20 iterations, 8 frames of one scene; a class counts verdicts, not accuracy. No accuracy appears on this page, and none follows from it: a probe trains 20 iterations on 8 frames and shows whether a combination works, not how good it is.

    How to read a row: C R L P are the four levels of the cell under GSNet, composes, runs, learns and predicts (✓ reached, ✗ not, ? undecided: not checked for a record of the first judge, unstable, not repeated for an unstable run nobody probed again). The Class of an option counts the methods under which it reached each level; levels with the same class are named together. A probe that predicted no grasp on any frame is greyed. The levels, the classes and their thresholds are defined on the measured page, Measured classes.
